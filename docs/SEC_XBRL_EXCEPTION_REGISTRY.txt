Reporting scope is a separate classification from taxonomy framework (US GAAP/IFRS) and from whether the context is dimensioned:
- Current audit captured only a dimensioned YES/NO flag, not the dimension axes and members. Therefore each existing tag row has reporting_scope=UNKNOWN.
- Future audits must capture dimension axes/members and classify scope as CONSOLIDATED, PARENT_ONLY/SEPARATE, SEGMENT, UNSEGMENTED, or UNKNOWN.
- Assign CONSOLIDATED or PARENT_ONLY/SEPARATE only when the filing context or statement presentation supports it. A dimensionless context is UNSEGMENTED; it is not, by itself, proof of consolidated scope.
- Never feed parent-only or segment facts into consolidated company totals. Keep unresolved scope out of automatic mapping until checked.

Review rules:
- Candidate metric is a name-based audit family, not an approved semantic mapping.
- A custom tag must be checked against the filing label, definition, calculation, context, and period before it is used.
- dimensioned=YES means a dimensional context was observed for this concept in the scanned filings; it does not by itself invalidate the concept.
- lease_keyword=YES means the tag name contains 'lease'; review lease treatment before using it for debt, D&A, or interest.
- Tags with no specific note remain PENDING REVIEW; none of the company-specific tags below were automatically added as aliases.
